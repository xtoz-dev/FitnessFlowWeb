# FitnessFlow Web

Installierbare FitnessFlow-Web-App (PWA) für iPhone und Desktop. Trainings-, Ernährungs-, Cardio- und Chat-Daten werden ausschließlich in `localStorage` auf dem jeweiligen Gerät gespeichert.

Auf dem iPhone in Safari öffnen → **Teilen** → **Zum Home-Bildschirm**. Die App öffnet anschließend im Vollbild und arbeitet nach dem ersten Laden offline.

GitHub Pages wird über `.github/workflows/deploy-pages.yml` bereitgestellt.
